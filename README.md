# Prizma Koşusu V3

Bu klasörü Flutter projesi olarak aç. Ana README bir üst klasördedir. Beş şerit, geç daralan köprüler, ortak üç can, hızlanan sonsuz koşu ve yalnız kristalle kazanılan puan sistemi vardır. AdMob test bağlantısı açıktır; ücretli mağaza varsayılan olarak kapalıdır. Gerçek sıralama için `PRISMA_API` tanımlanır.

```bash
flutter pub get
flutter devices
flutter run -d CIHAZ_KIMLIGI
```
